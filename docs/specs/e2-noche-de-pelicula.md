## Regla pura

Archivo futuro: `src/dominio/noche.ts`. No importa red, base de datos ni interfaz.

`validarTiempo(minutos)` acepta solo un entero entre 30 y 600. Cualquier otro valor, incluido vacío, decimal o texto, es inválido.

`duracionDeSesion(duraciones, pausaMinutos)` suma las duraciones y suma `pausaMinutos` por cada hueco. Con una película hay cero huecos. Con ninguna, el total es 0. La pausa de esta épica es 10.

`cabe(tiempoDisponible, duraciones, pausaMinutos)` es verdadero solo si todas las duraciones son enteros mayores que 0 y `duracionDeSesion` es menor o igual que el tiempo. Una duración ausente, cero o negativa hace que no quepa.

`cabeAgregar(tiempoDisponible, duracionesActuales, duracionNueva, pausaMinutos)` aplica `cabe` al conjunto actual más la nueva. Si la nueva no es un entero mayor que 0, no se puede agregar y el motivo es que no tiene duración conocida. Si el conjunto no cabe, el motivo dice cuánto queda y cuánto haría falta, incluida la pausa cuando ya hay al menos una película.

DEBE vivir en `src/dominio/` y recibirse el tiempo, las duraciones y la pausa.

NO DEBE llamar al catálogo ni al almacén.

NO DEBE usar `any`.

## Datos

Dos tablas nuevas. No modifican `mi_lista` ni el estado de sus filas.

`noche_sesion` guarda el plan. `noche_sesion_pelicula` guarda la copia de cada película en el orden en que se agregó. No hay clave foránea hacia `mi_lista`: si la persona borra el título de su lista, la copia sigue existiendo para poder marcarla como fuera del plan. Sí puede repetirse el mismo `tmdb_id` en sesiones distintas. No puede repetirse dentro de la misma sesión.

```sql
create table public.noche_sesion (
  id bigint generated by default as identity primary key,
  user_id uuid not null default auth.uid() references auth.users (id) on delete cascade,
  nombre text not null,
  tiempo_disponible_minutos integer not null,
  fecha_guardada timestamptz not null default now(),
  constraint noche_sesion_nombre check (
    char_length(btrim(nombre)) > 0 and char_length(btrim(nombre)) <= 80
  ),
  constraint noche_sesion_tiempo check (
    tiempo_disponible_minutos between 30 and 600
  )
);

create table public.noche_sesion_pelicula (
  id bigint generated by default as identity primary key,
  sesion_id bigint not null references public.noche_sesion (id) on delete cascade,
  user_id uuid not null default auth.uid() references auth.users (id) on delete cascade,
  tmdb_id integer not null,
  titulo text not null,
  duracion_minutos integer not null,
  poster_url text,
  orden integer not null,
  constraint noche_pelicula_tmdb check (tmdb_id > 0),
  constraint noche_pelicula_titulo check (char_length(btrim(titulo)) > 0),
  constraint noche_pelicula_duracion check (duracion_minutos > 0),
  constraint noche_pelicula_orden check (orden > 0),
  constraint noche_pelicula_unica unique (sesion_id, tmdb_id),
  constraint noche_pelicula_orden_unico unique (sesion_id, orden)
);

alter table public.noche_sesion enable row level security;
alter table public.noche_sesion_pelicula enable row level security;

revoke all on public.noche_sesion, public.noche_sesion_pelicula from public, anon;
grant select, insert, update, delete on public.noche_sesion, public.noche_sesion_pelicula to authenticated;

create policy noche_sesion_select on public.noche_sesion
  for select to authenticated using (auth.uid() = user_id);
create policy noche_sesion_insert on public.noche_sesion
  for insert to authenticated with check (auth.uid() = user_id);
create policy noche_sesion_update on public.noche_sesion
  for update to authenticated using (auth.uid() = user_id) with check (auth.uid() = user_id);
create policy noche_sesion_delete on public.noche_sesion
  for delete to authenticated using (auth.uid() = user_id);

create policy noche_pelicula_select on public.noche_sesion_pelicula
  for select to authenticated using (auth.uid() = user_id);
create policy noche_pelicula_insert on public.noche_sesion_pelicula
  for insert to authenticated with check (auth.uid() = user_id);
create policy noche_pelicula_update on public.noche_sesion_pelicula
  for update to authenticated using (auth.uid() = user_id) with check (auth.uid() = user_id);
create policy noche_pelicula_delete on public.noche_sesion_pelicula
  for delete to authenticated using (auth.uid() = user_id);
```

DEBE activar RLS y exigir `auth.uid() = user_id` en lectura y escritura, con `with check` en insert y update.

NO DEBE crear políticas para el rol anónimo.

NO DEBE guardar una sesión que cambie `estado` en `mi_lista`.

Al leer una sesión, el servicio compara cada `tmdb_id` con la lista actual. Si esa película ya no está por ver para esa persona, se marca fuera del plan y no entra en la suma que se muestra.

## Servicios

`src/services/duracion.ts` pide al catálogo la duración de una película. Devuelve conocida, desconocida o error. Una serie no se consulta para esta pantalla.

`src/services/sesiones.ts` lista, crea, actualiza y abre sesiones de la persona autenticada. Antes de crear o actualizar llama a `cabe`. Si no cabe, no escribe. Actualizar no cambia `tiempo_disponible_minutos`. Crear y actualizar no escriben en `mi_lista`.

DEBE pasar por estos servicios cualquier lectura o escritura de sesiones y cualquier consulta de duración.

NO DEBE un componente llamar al catálogo ni al almacén.

## Pantalla

Ruta futura `/noche`, dentro de la misma protección que el resto de la cartelera. En la barra, el enlace se llama Noche.

Piezas, todas con datos que les entrega la página:

- `SelectorDeTiempo` pide el tiempo y muestra el motivo si no es válido.
- `ListaQueCabe` muestra póster, título y duración, en el orden de la spec.
- `ListaNoDisponible` muestra las que no tienen duración y el motivo.
- `EstadoDeConsulta` muestra carga o error.
- `BorradorDeSesion` muestra las elegidas, la duración total, el tiempo restante, y permite quitar.
- `SesionesGuardadas` muestra nombre y fecha de guardado, y abre el detalle.

DEBE explicar por qué un agregado no entra.

NO DEBE ofrecer series ni películas que no están por ver.

NO DEBE agregar una película mientras su duración se está consultando o la consulta falló.
